# Seplos V3 Battery Sniffer (Home Assistant add-on)

Decodes the RS485 master/slave traffic of Seplos V3 multipack batteries
(Fogstar 16.1 kWh ECO) from a Waveshare RS485-to-Ethernet bridge and
publishes every pack to MQTT with discovery. Includes a live ingress panel.
See DOCS.md (the Documentation tab) for wiring, Waveshare settings and options.
